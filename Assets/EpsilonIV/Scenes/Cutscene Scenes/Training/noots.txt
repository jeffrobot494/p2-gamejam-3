When issues span across several axes:
Conflicts with the prompt → penalize Instruction-Following
Departures from the original/logical fit → penalize Image Consistency
Artifacts/tech flaws where the image has changed → penalize Quality
Artificial look introduced by the changes → penalize AI-ness/Naturaless

Human likeness in Image Consistency: If the prompt does not mention edits to a face or body, the completion should maintain the person’s likeness to the Original in fine detail.

Likeness can help break ties among weak completions, but it never outweighs Instruction Following.
A copy that ignores the prompt receives a low IF score even if likeness is high. Example for Instruction Following + Image Consistency scoring: “Insert Lady Gaga into a dance scene”: A dance scene is added and if:
A person resembling Lady Gaga is included (fine-grained likeness, facial details) → Heavily reward IF (6-7); High IC due to high likeness.
A woman with broadly correct context is included (e.g., woman, some general characteristics) but likeness is not perfect → Instruction Following ≥5; penalize likeness in Image Consistency.
A person who looks nothing like Lady Gaga is included (completely different person) → Penalize IF a lot; no need to consider in Image Consistency.
No person is added at all → Penalize IF even more; no need to consider in Image Consistency.
